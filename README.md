# Apex Analytics

**Enthusiast Used-Car Market Intelligence**

Apex Analytics is a personal data analytics portfolio project focused on the U.S. enthusiast and performance-car market.

The project will analyze used-vehicle listing data to understand how factors such as mileage, vehicle age, transmission, accident history, ownership history, model generation, and other enthusiast-relevant characteristics relate to asking prices.

## Project Goals

- Analyze pricing trends across enthusiast and performance vehicles
- Measure the relationship between mileage and asking price
- Investigate manual-transmission pricing premiums
- Compare depreciation patterns across models and generations
- Examine the effect of accident and ownership history on vehicle pricing
- Build an interactive BI dashboard for automotive market analysis

## Planned Tech Stack

- Python
- Pandas
- PostgreSQL
- SQL
- Power BI / Tableau
- Statistical analysis
- Git & GitHub

## Project Status

**Phase 0 — Dataset feasibility and exploratory audit**

The initial phase focuses on validating the dataset and determining which enthusiast vehicle models have enough observations for reliable analysis.
